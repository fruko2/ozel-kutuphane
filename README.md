# Kütüphane-i Şahsî

Flutter ile geliştirilen çevrimdışı öncelikli kişisel kütüphane uygulaması.

## Ubuntu üzerinde APK

Ubuntu bilgisayarda ARM64 release APK üretmek için
[`UBUNTU_DERLE.md`](UBUNTU_DERLE.md) belgesini izleyin.

## Redmi Note 13 Pro / Termux

Telefon üzerinde yerel derleme için [`TERMUX_DERLE.md`](TERMUX_DERLE.md)
belgesini izleyin.

Her iki yöntemde de APK yerel cihazda derlenir. GitHub yalnızca kaynak kodun
saklanması ve indirilmesi için kullanılır.
